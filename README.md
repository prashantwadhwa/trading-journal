Trading Journal 📈

A full-stack trading journal and analytics dashboard that helps retail traders track trades, analyze performance, and identify behavioral patterns.

Status: Early Development

Features
Trade Journal — Create, edit, delete, and filter trades.
Performance Analytics — Track win rate, total P&L, risk/reward ratio, and equity curves.
Behavioral Insights — Identify potential revenge trading and analyze performance by emotional state.
AI Reviews — Generate weekly performance summaries using AI.
CSV Import — Import trade history from CSV files.
Benchmark Comparison — Compare performance against the Nifty 50 (planned).

Features are under development and may not yet be available.

Tech Stack
Frontend: React, Vite, Tailwind CSS, Recharts
Backend: Node.js, Express
Database: PostgreSQL (Neon)
Auth: BetterAuth
ORM: Prisma
Scheduled Jobs: node-cron
AI: LLM API

Security
Passwords will be securely hashed.
Private routes will require authentication.
Users will only be able to access their own trading data.
